# 인테리어 AI 견적 스튜디오

공간 사진과 스타일을 넣으면 시공 후 실사 시안을 만들고, 실측 치수를 넣어 마감재·가구 수량과 견적까지 내는 인테리어 사업자용 웹 프로그램.

## 쓰는 순서
1. **사진·스타일** — 공간을 고르고 현장 사진을 올린 뒤 스타일을 고르고 "실사 만들기"를 누른다.
2. **실사 시안** — 시공 전 사진과 시공 후 실사를 나란히 본다. 추가 요청을 적어 다시 만들 수 있다.
3. **실측 치수** — 줄자로 잰 가로·세로·천장고, 문·창을 넣는다. 가구 크기와 단가도 여기서 고친다.
4. **견적** — 공간별 합계, 마감재 주문 수량, 가구 목록, 전체 금액. 줄마다 수정하고 엑셀용 CSV로 저장한다.

## 배포 (Render)
1. Render에서 New → Blueprint로 이 저장소를 연결한다 (`render.yaml` 사용).
2. 환경 변수 두 개를 Render 화면에서 직접 넣는다. 저장소나 채팅에 적지 않는다.
   - `GEMINI_API_KEY`: Google AI Studio에서 만든 API 키
   - `APP_PASSWORD`: 접속 비밀번호 (없으면 누구나 들어와 AI 비용을 쓸 수 있다)
3. 배포 뒤 로그인하고 주소 뒤에 `/api/ai-models`를 붙여 열면 이 키로 쓸 수 있는 모델 이름이 나온다.
   실사가 "모델을 찾을 수 없습니다"로 실패하면 여기서 이미지 모델 이름을 찾아 `GEMINI_IMAGE_MODEL`을 고친다.

## 내 컴퓨터에서 실행
```bash
AI_MOCK=1 python3 app/server.py
```
http://127.0.0.1:8780 을 연다. `AI_MOCK=1`은 실제 AI 대신 정해진 답을 돌려주는 확인용 모드다.

## 알아 둘 점
- 노임단가는 대한건설협회 시중노임단가 기준이며 일부 직종은 추정값이다. 화면에서 고친다.
- 품(인/단위), 재료·가구 단가, 포장 단위는 참고용 기본값이다.
- 실사 이미지는 분위기 시안이며 이미지 속 치수는 정확하지 않다. 견적은 3단계에서 넣은 실측 치수로 계산한다.
- 프로젝트와 사진은 쓰는 기기의 브라우저에만 저장된다. 다른 기기·직원과 공유되지 않는다.
- 하루 실사 이미지 수는 `DAILY_RENDER_LIMIT`(기본 60장)으로 제한한다.
